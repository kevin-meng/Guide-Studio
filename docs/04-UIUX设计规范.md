# Guide Studio · UI / UX 设计系统 V1

## 1. 视觉关键词与原则

**专业、简洁、轻盈、可信、安静。** 参考成熟生产力工具的设计方法，不机械复制单一品牌界面。视觉优先级：任务操作 > 画面内容 > 导航 > 装饰。避免大面积渐变、过度阴影、浮夸动画和大幅营销插画。首版截图内容是整个编辑器唯一主角。

## 2. Design Tokens

| 变量 | 色值 | 用途 |
|---|---|---|
| `--ink` | `#202632` | 标题、正文 |
| 页面背景 | `#F8F9FB` | 工作台外层 |
| 面板 | `#FFFFFF` | 画板、列表、边栏 |
| `--muted` | `#8C95A5` | 辅助说明 |
| `--line` | `#E8EBF0` | 微弱边框 |
| `--accent` | `#394D98` | 唯一品牌主强调色、主要按钮 |
| `--accent-hover` | `#2F4083` | 主要按钮 Hover |
| 红标注 | `#E5484D` | 操作重点默认 |
| 橙标注 | `#F59A43` | 次要提醒 |
| 蓝标注 | `#377AD9` | 说明定位 |
| 深标注 | `#273247` | 浅底高对比标记 |

中文字体优先系统 PingFang SC / 微软雅黑，英文字体使用 Inter / 系统 SF Pro。字号：页面标题 25–30px，区块标题 18px，正文 12–14px，辅助 10–12px。主要圆角 9–14px，阴影只用于提升悬浮层次，不制造巨大视觉对比。

## 3. 页面信息架构

- `/` 工作台：欢迎语、教程总数/已发布/待完善、最近编辑、快速新建。
- `/?view=guides` 教程库：搜索、状态筛选、继续编辑。
- `/?view=faqs` 问题库：录入/关联/查看/删除。
- `/?edit={id}` 教程编辑器：标题、步骤、截图画布、工具栏、说明与分类。
- `/?view=settings` 设置：云端登录、协作与数据安全提示。
- `/g/{slug}` 匿名阅读：标题、受众、逐步图片与说明；不出现编辑工具。

## 4. 桌面端编辑器（≥761px）

```
+--------------------------------------------------------------------------+
| ← | 教程标题（直接修改）       已保存在本机 | 云端保存 | 导出 | 发布   |
+----------------+---------------------------------------------------------+
| 操作步骤        | STEP 01 / 04                                            |
| [01 缩略图]     | [选择][箭头][方框][圆圈][画笔][文字][序号][隐私遮挡] ...|
| [02 缩略图]     | +-----------------------------------------------------+ |
| [03 缩略图]     | |                                                     | |
| [添加步骤]      | |                 截图标注画布                         | |
|                | |                                                     | |
|                | +-----------------------------------------------------+ |
|                | [替换本张]                         [导出PNG] [删除步骤] |
|                | [步骤说明文本区域]                                     |
|                | [分类]                     [适用对象]                  |
+----------------+---------------------------------------------------------+
```

侧边步骤列表宽 239px，可用上下箭头排序；中间内容最大宽度 860px，避免大屏下表单过宽。步骤文字独立在画布下方，而不是塞进画布图片。工具栏控制属性减少到工具、颜色、撤销恢复。

## 5. 移动端（≤760px）

- 不出现桌面侧栏，顶部紧凑放返回、标题、云端保存、导出、发布。
- 步骤导航变为横向可滚动的序号胶囊，画布铺满可用宽度。
- 标注按钮为 ≥30px 点击面，重要触点具备足够间距；固定底部条「添加步骤」「发布教程」。
- 避免 `hover` 专属功能或随鼠标漂移的菜单。
- 输入文字时优先使用清晰弹窗与系统键盘，不压缩绘图区域。
- 当前版对小屏仅实现画布自适应；下一版优先改进双指缩放和局部精确定位。

## 6. 交互状态

| 状态 | 行为 | 反馈 |
|---|---|---|
| 空教程 | 中央显示导入图片区 | “选择截图”清晰主按钮 |
| 添加图片 | 相册多选 / 拖入 / 粘贴 | 自动创建步骤并跳转第一张 |
| 选择工具 | 当前按钮底色与颜色变化 | 光标转变（桌面） |
| 点击图层 | 虚线边界 / 可拖动 | 删除或调整尺寸 |
| 绘制 | Pointer Events；归一化坐标 | 画完立即更新画布 |
| 保存 | 输入 350ms 后写 IndexedDB | “已保存在本机” |
| 云端保存 | 未登录先提示登录 | 保存完成提示；出错不清除本地稿 |
| 发布 | 检查全部步骤必须有图 | 成功显示可复制链接，失败明确原因 |
| 导出 | PNG 或包含全部截图的离线 HTML | 文件名包含教程标题或步骤号 |

## 7. 可访问性与质量标准

- 所有图标按钮应有 aria-label/title，导航按键可聚焦。
- `:focus-visible` 对键盘用户有清晰轮廓。
- 内容与辅助文字需满足合适的对比度；白底浅灰说明文字已尽量淡化但仍需正式 WCAG 工具检查。
- 表单有 label，错误和状态通过 toast 显示（role=status）。
- 移动端必须真机检查 Safari、微信 WebView 顶底安全区、系统键盘与触摸落点。
- 不使用动画阻止快速操作，图片本地处理无需发起 GPU/AI 远程服务。
