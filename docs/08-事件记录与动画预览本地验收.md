# Guide Studio V1.1 · 标注事件与视频预览交付说明

**分支**：`design/annotation-timeline-v1`；基于首轮 `feat/guide-studio-v1`。本次变更为可本地体验的第一轮实现，默认无需登录。

## 已实现

- 新建标注保存稳定 `id`、单步骤单调递增 `createdSeq` 和 `createdAt`；旧版无 ID 标注按数组顺序生成默认动画（明确标记 `inferred-legacy`，并不伪造历史）。
- 每一轮鼠标/触控操作合并为一个编辑事件；新增、移动/缩放、文本修改、删除、撤销、重做均有记录；画笔记录带相对毫秒数的限量采样点（坐标归一化）。
- 浏览器 IndexedDB 升级至 V2，新增 `annotation_events`；事件随浏览器本地保存。支持导出 JSON 供备份与后续排错。
- `Guide.steps` 保存最终标注稳定 ID、顺序和可选 `presentation`，云端跨设备可恢复最终演示顺序；私有的完整编辑事件日志**当前仅本机保存**，不是跨设备同步功能。
- 「动画预览」默认依照最后有效图形的创建顺序播放，忽略被删的标注和作者纠错过程；在弹窗可上移/下移标注的播放顺序。
- 通过 Canvas 在浏览器本地生成 9:16 竖版教学演示，图片保持比例不拉伸，包含步骤描述字幕、默认简洁动效。
- 可尝试 `captureStream()` + `MediaRecorder` 实时导出视频：浏览器支持 MP4 时采用 MP4，否则 WebM；不支持时保留动画预览、PNG 与 HTML 导出。
- 隐私遮挡（mask）每帧必须先于可动画标注绘制，从不作为后进入场的动画；匿名教程仍只返回压平 PNG，不包含事件/原图/视频脚本。

## 本地启动

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 如需云端保存与登录，配置独立的管理员邮箱、密码和 SESSION_SECRET。
uvicorn server.main:app --reload --port 8000
```

浏览器打开 `http://localhost:8000`：新建教程 → 添加截图 → 画圆、箭头、文字或隐私遮挡 → 选中标注移动 → 撤销/重做 → 点击顶部或底部「动画」→「播放」→ 上/下调整顺序 → 「导出视频」或「导出编辑记录 JSON」。

> 默认浏览器本地模式不需要 COS、账号或公网部署。图片在本机处理；视频输出取决于浏览器编解码支持，**不是跨平台稳定 MP4 服务**。

## 数据存储与兼容

- 本地草稿：IndexedDB `guides`。私有编辑事件：`annotation_events`，按 `guideId`/`stepId` 检索；导出 JSON 为本机备份。
- 服务器草稿：`Guide.steps` 的 `annotations / nextAnnotationSeq / nextEventSeq / timelineSource / presentation`。旧教程缺少这些键仍可正常读取。
- 服务器公开快照：只保存 `GuidePublication.steps` 的 `id / description / publicAssetId`。
- `presentation.cues` 引用稳定 `objectId`，缺失或者删除的图层不会出现在播放中。
- **局限**：刷新浏览器后，历史事件依旧存储，但旧的 35 次撤销栈不恢复；需保留浏览器存储或自行导出备份。当前没有云端完整事件日志 API，也没有视频资产上传及后端渲染队列。

## 后续风险与上线条件

1. 如需跨设备完整编辑审计，应新增受鉴权事件日志 API、导出与容量管理，不应无限增大现有 `Guide.steps` JSON。
2. 移动微信内置浏览器对视频录制/下载能力可能受限；需在真实设备做功能检测，失败展示清晰提示。
3. `MediaRecorder` 为实时录制，长教程会较慢；未来可以增加 WebCodecs / 服务端队列来稳定高分辨率 MP4。
4. 私有源截图可能包含敏感数据；标注记录与字幕不进入公开 API。COS 上的源文件需配置权限、备份与生命周期。
5. 上线前仍需主 V1 文档列出的 HTTPS、反向代理、安全和真机验收。
