# Guide Studio · 产品需求文档 V1

> 日期：2026-10-11。阶段：首个可使用版本。业务种子：言序 Yanxu。产品应保持品牌与数据隔离，未来独立运营。

## 1. 问题与用户

言序小程序的功能丰富，俱乐部管理员、会议组织者、普通会员、访客常在微信群询问类似问题；少数志愿者重复回答，无法规模化。教程由截图、突出操作位置的矢量标注和简洁步骤文字构成。团队需要低学习成本地协作生成与更新教程，用户需要稳定链接和自助检索。

### 用户角色

| 角色 | 目的 | 首要任务 |
|---|---|---|
| 志愿者 / 编辑者 | 用手机快速制作图文教程 | 导图、标注、写文字、保存 |
| 内容负责人 / 管理员 | 维护问题池和知识规范 | 归类、关联、管理成员 |
| 普通用户 | 自己完成操作 | 看图、按步骤执行、分享链接 |
| 后续 SaaS 客户 | 为不同产品管理教程 | 工作空间、项目与权限 |

## 2. 核心原则

1. **先完成，再美化**：基本流程不应超过 `新建 → 选图 → 标记 → 写说明 → 导出/发布`。
2. **本地速度**：图片处理在浏览器 Canvas 完成；不使用大模型和服务端生成图片。
3. **可修改**：编辑源保存矢量标注 JSON，公开阅读图为压平 PNG。
4. **手机优先**：无悬浮菜单依赖；点击、拖动适配触屏；电脑增强粘贴与快捷键。
5. **不强迫登录**：本地创作和导出无需账号；公开链接需要云端身份与持久化。
6. **保留稳定链接**：已发布快照不受草稿修改影响，重新发布后使用同一 slug。

## 3. 已交付工作流

### 流程 A：志愿者手机制作

- 打开编辑器 → 新建教程。
- 从相册多选截图（可直接新建多个步骤；第一张自动放入空步骤）。
- 选择标注工具：箭头/圆/方框/画笔/文字/数字/隐私遮挡，触摸绘制；回到选择模式移动对象。
- 为每一步输入文字说明，添加新步骤，调整顺序，选择分类与受众。
- IndexedDB 自动存稿；无需账号即可导出 PNG 或独立 HTML。
- 登录后「云端保存」；再次点击「发布教程」会生成最终图片、生成/更新公开链接。

### 流程 B：电脑集中制作

- Ctrl/Cmd+V 粘贴截图、拖拽多张图；工具栏与手机一致。
- 选择标注、按 Delete 移除，Ctrl/Cmd+Z 撤销，Shift+Ctrl/Cmd+Z 重做。
- 左侧逐步导航和调整次序；顶部手动云端保存；一键生成分享链接。

### 流程 C：用户阅读

- 公开 `/g/{slug}` 无需登录，按顺序呈现高清图片和独立文字。
- 分享链接保持不变，阅读页无复杂编辑工具。

### 流程 D：高频问题管理

- 记录用户原始提问，可先不关联教程。
- FAQ 可关联已存在的标准教程，避免同义问题重复制作。
- 项目作为 FAQ 和 Guide 的归属边界。

## 4. V1 功能边界

### P0 实现

截图多选、粘贴、拖入、替换；编辑标注；步骤创建/删除/上移/下移；标题/分类/受众/说明；本地草稿自动保存；PNG/HTML 导出；账户登录；云端同步；发布公开链接；基础 FAQ；管理员通过 API 添加成员。

### P1 尚未做

图片拖拽列表重排、触控双指缩放与吸附辅助线、批量 FAQ CSV 导入、图形复制与多选、复杂文本排版、编辑审批工作流、教程回滚 UI、使用统计、项目切换 UI、成员管理 UI。

### P2 不做

AI 自动看图生成教程、视频自动录制转教程、实时多人协同、收费订阅和商业化计费。

## 5. 信息架构

```
Workspace (团队 / 商业客户)
  └─ Project (产品，例如言序)
     ├─ FAQ (用户问题：同义表达、受众、分类、教程映射)
     └─ Guide (标准教程：标题、适用用户、正文状态、发布 slug)
        └─ Step[] (操作说明、原始图片、标注 JSON、公开 PNG)
```

一篇 Guide 可以被多条 FAQ 引用。当前 Step 放在 Guide JSON 中进行整体事务更新，后续统计或共享步骤再拆成关系表。

## 6. 产品指标 / 验收门槛

- 目标：熟悉工具的志愿者 3 分钟内完成 3 张截图的简单教程（真实用户测试验证）。
- 目标：20–30 篇高频教程覆盖首批言序常见场景；无需一次做完几百个问题。
- 不允许：未授权查看原图、编辑过程静默丢稿、发布后失去稳定链接。
- 主要监测：教程创建成功率、失败上传率、跨设备打开率、微信内置浏览器可访问率、FAQ 自助解决率。

## 7. 首版限制说明

没有对手机相册做“自动监听”。浏览器不能可靠读取所有新截图；用户从系统相册手动多选导入。浏览器也不能在所有微信 WebView 中保证图片保存到相册，V1 提供标准下载，仍须在真机测试 Android/iOS 与微信内置浏览器行为。
