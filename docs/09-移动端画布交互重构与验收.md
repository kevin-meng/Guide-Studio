# Guide Studio V1.2 · 移动端画布重构与验收

日期：2026-10-11  
开发分支：`fix/mobile-canvas-editor-v1`  
状态：已实现代码，**尚需 iOS Safari / 微信内置浏览器 / Android 微信真机验收**。

## 目标与交互原则

普通用户完成教程时先按顺序上传截图，每张截图为独立步骤卡片，并分别写说明；**点击截图才进入编辑状态**。此时底部出现仅针对这张截图的标注工具。页面顶部始终保持「发布教程」，不在底部再显示发布、动画预览和教程导出等重复操作。桌面端保留原 V1 的大屏编辑布局。

手机端步骤缩略条可点按快速定位；尝试长按并移动至目标步骤来重新排序；仍可使用每个步骤卡片右上角的 ↑ / ↓ 按钮排序。点击卡片上的替换按钮可替换该图，其他步骤不受影响。

## 用户实际流程

1. 新建教程，上传多张截图；页面展示按步骤排列的卡片，每张图下方可写操作说明。
2. 点击某一张图片，卡片进入编辑态，同时手机底部出现画笔/荧光笔/马赛克/方框/圆圈/箭头/文字/序号/隐私遮挡及颜色/粗细/撤销/恢复/删除/缩放复位。
3. 单指按已选工具进行标注；双指进入缩放平移，自动放弃尚未提交的绘制手势。**文字与序号仅在完整单指轻点抬起后触发输入框**。
4. 点击「完成」回到多卡片浏览，再点击下一张进行编辑。
5. 通过步骤条长按排序或卡片 ↑ / ↓ 按钮排序；可单独替换图片。发布/云端操作仍从顶部完成。

## 图像与视频隐私规则

- `mask`：实色覆盖隐私区域，在导出 PNG 和视频前不可逆合成。
- `mosaic`：像素化遮盖，可以用于界面弱化/普通局部遮盖；**不保证完全无法辨识原始敏感信息**，敏感信息必须使用实色遮挡。
- 视频准备阶段先在**私有离屏 Canvas** 合成所有最终实色遮挡与马赛克，录制画布全程只绘制处理过的脱敏底图，再叠加非隐私标注。绝不能先绘制原图后才出现遮挡动画。
- 演示时间线排除 `mask` / `mosaic` 两类隐私处理，不允许播放“逐渐显示遮挡”的镜头。
- 保持非破坏式图层，原始截图只在授权空间或本机保存；公开教程只使用压平图。

## 兼容性与限制

- 不引入前端新运行时依赖，沿用原生 ES Modules、Canvas、Pointer Events 和 IndexedDB。
- 高分辨率截图和大量步骤时需实际测试 iOS 内存占用；当前预览卡片仍各有 Canvas，未来可虚拟化。
- 在微信内置浏览器和 iOS Safari 上，长按可能与系统文字选择/网页滚动冲突，因此始终保留 ↑ ↓ 备用。
- 普通图层命中区域、图形缩放手柄和图片替换后的旧标注坐标需要真实设备抽查。
- 当前无法在自动化测试环境完成浏览器端到端页面导航（浏览器返回 `ERR_BLOCKED_BY_ADMINISTRATOR`）；不要声称已经完成真机或端到端验证。

## 回归验收清单

1. 使用 iPhone/Android 从相册选 3 张截图：应该出现 3 个步骤卡片，每张都可填独立描述。
2. 没选图片时底部不能有「发布/导出/动画」重复菜单；点击第二张后才出现标注工具。
3. 用单指画圆，拖拽圆圈调整位置、粗细；切换画笔和荧光笔，检查导出 PNG 与画面一致。
4. 用两指同时触摸「文字」或「圆圈」工具下的画布，缩放/平移后不能弹输入框，也不能多出一个形状。
5. 在截图里将手机号用**实色遮挡**，马赛克用于其他演示区域；导出 PNG / 动画视频确认从第一帧不会泄露手机号。
6. 点击上方步骤条，再长按排序；如果系统拦截长按，测试 ↑ ↓ 备用。
7. 刷新浏览器、重新打开旧教程、云端保存与发布，确保多步骤描述、标注与图文导出正常。
8. iOS 微信内置浏览器、Android 微信、iOS Safari、桌面 Chrome/Edge 各自按此清单测试一次。

## 本地启动

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 设置自己的 SESSION_SECRET / BOOTSTRAP_ADMIN_EMAIL / BOOTSTRAP_ADMIN_PASSWORD
set -a; source .env; set +a
uvicorn server.main:app --reload --port 8000
```

测试：`node --test tests/*.test.mjs && python -m pytest -q tests && node --check web/app.js && node --check web/canvas.js && node --check web/video.js`。
