# Guide Studio · V1 测试、验收、风险与迭代路线

## 1. 自动回归范围

执行：

```bash
python -m pytest -q tests/
python -m compileall -q server/
node --check web/app.js
node --check web/canvas.js
```

`tests/test_api.py` 已涵盖：初始化账号、错误登录、未授权接口、创建云端教程、源图/公开图隔离、发布前匿名 404、发布后匿名可读、安全 PNG 返回、更新草稿不影响旧发布快照、revision 冲突 409、FAQ 创建删除、来源 Origin 检查、错误图片类型、编辑者权限限制。

自动 API 通过不等于整个 UI 或云端接入完成验收，需按下列手工矩阵补齐。

## 3. 编辑器验收案例

1. 图片加载和 Canvas 比例一致，保存 PNG 与原图尺寸一致；旋转/高 DPI 图像需要专项检查。
2. 连续输入文字与快速绘制，不出现同一对象多次、标注丢失。
3. 选中矩形、圆形、遮挡区，移动及右下角调整大小后能还原；箭头可移动。
4. 撤销/重做至少支持 30 个操作；删除标注仅删当前对象。
5. 图片上画“遮挡”后，公开平面 PNG 中敏感信息不可辨识；原图 URL 匿名请求必须 404。
6. 关闭页面再打开，本地草稿恢复；模拟断网后手动导出 HTML。
7. 公开旧版教程时新修改仅在本地/云端草稿展示，重新发布才更新公共内容。
8. 同一教程从两台设备编辑，较晚写入的冲突必须返回 409，不静默覆盖。
9. 发布过程中若任何上传失败，不能显示“已发布”；可继续编辑并重试。
10. 需验证中断/剩余配额不足时本地保存有显式错误反馈。

## 4. 业务验收试点

推荐找 5–10 位不同手机与经验层次的言序志愿者试用，先做 20–30 篇最高频教程。记录每篇制作耗时与交互错误，目标为“熟悉工具后 3 分钟完成一篇 3 步教程”。同时邀请普通会员仅根据教程完成操作，以“独立完成率”评估内容质量，而不是只观察页面美观。

## 5. V1 已知问题与上线阻断项

| 项目 | 级别 | 说明 / 对策 |
|---|---|---|
| 手机画布双指缩放与精细定位 | P1 | V1 有屏宽适配和拖动绘图，双指缩放需专项设计 |
| 大图 / 多图 IndexedDB 容量 | P1 | 高分辨率图片会使 dataURL 占用大量空间，加入空间提示与 Blob 存储 |
| 成员管理 / 忘记密码 | P1 | 首版只有管理员 API，正式外部开放前需 UI 与邀请/重置 |
| 登录防爆破、CSRF token | P0 安全加固 | 需要代理限速、会话管理、CSRF 防护再开放互联网注册 |
| COS 真桶上传与临时下载 | P0 部署 | 需要真实密钥/桶配置联调，不能仅凭模拟测试视为通过 |
| 客户端 UI 回归 | P0 体验 | 当前环境中受浏览器安全策略限制，未完成真实浏览器视觉自动化验收 |
| API schema migrations | P0 运维 | V1 新库 create_all；第二次 schema 升级前加入 Alembic |
| 大规模公开流量时资产访问性能 | P1 | 目前依据发布快照校验；大规模时维护资产引用索引与缓存 |
| 图像攻击 / EXIF / 头信息 | P1 | 发布 PNG 压平会清除大部分附带元数据，源图仍应检测与脱敏 |
| 公开阅读 H5 嵌入言序 | P1 | 微信域名白名单、WebView 与用户回跳需联合测试 |

## 6. 迭代顺序

### V1.1 — 体验与稳定性（优先）

- 手机双指缩放、精细移动标注和撤销历史持久化。
- IndexedDB Blob 存储与容量显示，明确离线/同步状态。
- 编辑器剪切/复制图形、步骤拖拽排序、基础图片裁剪。
- 真机 E2E 测试、COS STS 上传与对象管理、API 登录限速。

### V1.2 — 言序内容协作

- Excel/CSV FAQ 批量导入、重复问题检测、多人任务认领与审核状态。
- 管理员可视化成员邀请、密码重置、教程审核与历史回滚。
- 帮助中心角色过滤与言序小程序内入口；记录有帮助/没帮助反馈。

### V2 — 可独立服务客户

- 多租户工作空间 UI、公开帮助中心模板/自定义域名、多语言与 SEO。
- 知识检索、FAQ AI 辅助分类、图文自动草稿（人工审校）；按组织付费订阅。
- 开放 API / MCP / Webhook（按需）与资产生命周期治理。

## 7. 完成定义

此次 V1 交付定义是**已完成代码、模型、基本使用流程、开发文档及 API 自动化验证**；生产可用性必须以真机体验、COS 实桶、HTTPS/登录安全加固以及部署复验为依据。未做的功能应真实记录，不能用静态按钮或假后台数据宣称完成。
